# Worked example

These are corpus fixtures: realistic holiday pages that compile cleanly but carry planted defects.
Between them they exercise **every category and subcategory** in the [reference](/spec/reference),
plus the **look-alikes that must not be flagged**. They are the human-readable seed of the
[corpus](/spec/corpus).

A fixture is allowed to be ugly — being broken is its whole specification. That is the opposite job
from the [golden page](/problem/reader-failures), which stays clean to teach the style.

The request driving the pages:

> Find flights, accommodation, and a transfer for a holiday to France in **July 2026**, for
> **1 person**, under **£1,000**. Prefer a sunny destination.

## Fixture 1 — the itinerary

Carries the **Links**, **Clarity**, and **Mismatch** defects, because those sit naturally in real
prose and cards. It looks plausible; the trip is quietly in the wrong month, over budget, and booked
for two.

## Coverage — what the reviewer must flag

Every subcategory below is planted in one of the two fixtures. Three are purely structural and only
exist as real run-against fixtures (a page nothing links to, a server returning a soft-404, docs
naming a function the repo lacks) — they cannot be shown in an embedded mock, so they are marked
**real fixture**.

### Links

| Subcategory | Planted as | Check | Result |
|---|---|---|---|
| `BROKEN_INTERNAL_LINK` | "airport transfer guide" → `/guides/transfers`, which does not exist | Mechanical | Blocking |
| `BROKEN_ANCHOR` | "packing checklist" → `#packing`, no such section on the page | Mechanical | Blocking |
| `MISSING_IMAGE` | `nice-promenade.jpg` does not render | Mechanical | Blocking |
| `BROKEN_EXTERNAL_LINK` | "partner-bookings.example/holiday/nce-2026" returns 404 | Mechanical | Blocking |
| `SOFT_404` | the "weather page" link returns `200` but the page says it has moved | Text review | Report · *real fixture* |
| `ORPHANED_PAGE` | a corpus page that no nav or page links to | Mechanical | Blocking · *real fixture* |

### Rendering

| Subcategory | Planted as | Check | Result |
|---|---|---|---|
| `RENDERED_BROKEN` | "trip at a glance" shows raw `graph LR` source (itinerary) | Screenshot | Report |
| `DIAGRAM_SYNTAX_ERROR` | the comparison diagram is a red parse-error box | Screenshot | Report |
| `TRUNCATION` | the comparison page is clipped mid-sentence | Screenshot | Report |
| `TEXT_LEGIBILITY` | the 12-column table is set at 9px | Screenshot | Report |
| `FLAT_COLOUR` | the comparison page is a uniform grey wall | Screenshot | Report |
| `WEAK_HIERARCHY` | nothing on it signals what matters most | Screenshot | Report |
| `HIGH_DENSITY` | a 12-column table with no breathing room | Screenshot | Report |

### Clarity

| Subcategory | Planted as | Check | Result |
|---|---|---|---|
| `ACRONYM_UNEXPANDED` | `OTA`, `FCDO`, `TGV` used with no expansion | Text review | Report |
| `ASSUMED_JARGON` | "just bagsy a fixed-fare transfer off the rank" | Text review | Report |
| `MISSING_WHAT_WHY` | the page opens with output, never saying what it is or who it is for | Text review | Report |
| `MISSING_DOES_NOT` | it never states what it excludes (insurance, visas, baggage) | Text review | Report |
| `SIMPLER` | the room options are a run-on paragraph that should be a table | Text review | Report |

### Mismatch

| Subcategory | Planted as | Check | Result |
|---|---|---|---|
| `WRONG_CLAIM` | "comfortably under your £1,000 budget" beside a stated total of £1,180 | Text review | Report |
| `CONTRADICTS_PAGE` | request is for 1 person; the room is a twin for 2 guests | Text review | Report |
| `INCONSISTENT_TERM` | the destination is called both "the Riviera" and "Côte d'Azur" | Text review | Report |
| `BREAKS_STANDARD` | the footer claims acronyms are expanded "per our standard"; they are not | Text review | Report |
| `UNVERIFIABLE` | "the sunniest city in Europe" — no source, cannot be checked | Text review | Report |
| `IMAGE_MISMATCH` | the map is labelled "Paris" under a Nice recommendation | Screenshot | Report |
| `STALE_REF` | docs naming a code symbol the repo no longer has | Mechanical | Blocking · *real fixture* |

## Coverage — what it must ignore

The fixtures also plant look-alikes. A reviewer that flags these is one authors learn to mute, so the
corpus tests them as deliberately-fine cases.

| Looks suspicious | Why it is fine |
|---|---|
| `https://example.com/book?dest=NCE` in the code block | A placeholder in example code, not a live docs link |
| `ntfy.sh/your-trip-alerts` in the shell snippet | A placeholder topic for a reader to replace |
| `EHIC` in the transfer note | Expanded inline — "European Health Insurance Card" |
| "TODO: add winter options" under *Winter alternatives* | An explicit stub, known incomplete work |
| an intentional "Page not found" demo in an error-handling guide | The 404 is the example | 

:::info These are mocks, on purpose
The embedded pages illustrate the defects; they are not pages the tool runs against. The executable
fixtures — pages that genuinely 404, genuinely render Mermaid as text — live as test assets outside
the docs build, so they cannot break this site. This page is their specification.
:::
